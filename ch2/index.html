Chapter 2 · Planar Rigid Body Kinematics

A particle is a point; a rigid body is a whole object that can translate and rotate. This chapter answers one question: if you know how one point of a body moves and how fast the body turns, how does every other point move? Each idea comes with an animation you can drive yourself.

The big idea

For any two points A and B on the same rigid body moving in a plane,

$$\mathbf v_B = \mathbf v_A + \boldsymbol\omega\times\mathbf r_{B/A}, \qquad \mathbf a_B = \mathbf a_A + \boldsymbol\alpha\times\mathbf r_{B/A} - \omega^2\,\mathbf r_{B/A}$$

These two equations, plus a careful drawing, are all you need for the whole chapter. The body has one angular velocity $\boldsymbol\omega$ and one angular acceleration $\boldsymbol\alpha$, no matter which pair of points you use. Sections B and C are two ways of using these equations efficiently.
