Chapter 1 · Particle Kinematics

Kinematics is the geometry of motion: how to describe where a point is, how fast it moves and how its velocity changes, without yet asking which forces cause it. In this chapter a body is shrunk to a single point, a particle, and we learn several ways to write its velocity and acceleration. Each way is a different set of unit vectors, chosen to make a particular problem easy.

The big picture

The velocity and acceleration of a particle are vectors, and a vector does not care how you describe it. What changes from one description to the next is only the set of unit vectors you use to write the components:

DescriptionUnit vectorsBest when
Cartesian$\hat{\mathbf i}, \hat{\mathbf j}, \hat{\mathbf k}$ (fixed)$x(t)$, $y(t)$ are known, or the motion is guided by straight slots
Path$\hat{\mathbf e}_t, \hat{\mathbf e}_n$ (follow the path)you know the speed and the shape of the path (cars, roads, loops)
Polar / cylindrical$\hat{\mathbf e}_r, \hat{\mathbf e}_\theta$ (and $\hat{\mathbf k}$)distance and angle from a fixed point are measured (radar, rotating arms)

The Cartesian unit vectors never change. The path and polar unit vectors turn as the particle moves, and their rates of turning are the source of the "extra" terms such as $v^2/\rho$, $-r\dot\theta^2$ and $2\dot r\dot\theta$.
