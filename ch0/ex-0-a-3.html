Example 0.A.3From rotated xy components back to XY components

vectorsunit vectorsprojection

Problem

The vector $\mathbf b$ is given in terms of its $xy$ components as

$$\mathbf b = 3\hat{\mathbf i} - 5\hat{\mathbf j}$$

The $xy$ axes are turned counterclockwise from the $XY$ axes by the angle $\theta = 36.87°$, so that $\cos\theta = 0.8$ and $\sin\theta = 0.6$.

Find the $XY$ components of $\mathbf b$.

Solution

Try the problem first, and then open one step at a time to check your work.

Step 1 · Sketch the two sets of axes

This is the reverse of Example 0.A.2. The vector is known in the purple $xy$ axes, and we want its components along the grey $XY$ axes.

Step 2 · Write the old unit vectors in terms of the new ones

Seen from the $xy$ axes, the $XY$ axes are turned clockwise by $\theta$. Therefore

$$\hat{\mathbf I} = \cos\theta\,\hat{\mathbf i} - \sin\theta\,\hat{\mathbf j} = 0.8\,\hat{\mathbf i} - 0.6\,\hat{\mathbf j}$$ $$\hat{\mathbf J} = \sin\theta\,\hat{\mathbf i} + \cos\theta\,\hat{\mathbf j} = 0.6\,\hat{\mathbf i} + 0.8\,\hat{\mathbf j}$$
Step 3 · Project the vector onto each fixed unit vector $$b_X = \mathbf b\cdot\hat{\mathbf I} = (3)(0.8) + (-5)(-0.6) = 2.4 + 3.0 = 5.4$$ $$b_Y = \mathbf b\cdot\hat{\mathbf J} = (3)(0.6) + (-5)(0.8) = 1.8 - 4.0 = -2.2$$
Step 4 · Check the length $$|\mathbf b| = \sqrt{3^2 + (-5)^2} = \sqrt{34}, \qquad \sqrt{5.4^2 + (-2.2)^2} = \sqrt{29.16 + 4.84} = \sqrt{34}$$

The length is unchanged, which confirms the arithmetic.

Answer

$\mathbf b = 5.4\,\hat{\mathbf I} - 2.2\,\hat{\mathbf J}$
