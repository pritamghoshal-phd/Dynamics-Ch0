Example 0.C.3Speed from the acceleration as a function of time

scalar kinematicsintegration

Problem

The acceleration of point P, which travels on a straight-line path, is given by

$$a(t) = 6\sin 2t, \qquad v(0) = 4$$

Find the speed of P as a function of time.

The book does not state units. The animation uses metres for $s$ and seconds for $t$.

Solution

Try the problem first, and then open one step at a time to check your work.

Step 1 · Draw the kinematics diagram

The acceleration is known as a function of time. It changes sign, so P alternately speeds up and slows down, but we will see that it never stops.

Step 2 · Separate the variables

Because $a = dv/dt$, we can write $dv = a\,dt$ and integrate from the known starting state, $v = 4$ at $t = 0$.

$$\int_{4}^{v} dv = \int_{0}^{t} 6\sin 2\tau\,d\tau$$
Step 3 · Integrate $$v - 4 = \Big[-3\cos 2\tau\Big]_0^t = -3\cos 2t + 3$$
Step 4 · Solve for the speed $$v(t) = 7 - 3\cos 2t$$

At $t = 0$ this gives $v = 7 - 3 = 4$, which matches the starting speed. The speed varies between 4 and 10 and is never negative, so P always moves forward.

Answer

$v(t) = 7 - 3\cos 2t$
