Example 6.B.12Overshoot past static equilibrium

damped free responsestatic equilibriumovershoot

Problem

A block of mass $m$ hangs from the ceiling by a spring of stiffness $k$ and a dashpot with constant $c$, side by side. The block is released from rest under the action of gravity. We take the release position to be the one where the spring is unstretched, which is what “released under the action of gravity” describes. The coordinate $x$ is measured downward.

Find the initial overshoot past the static equilibrium state of the system.

Use $m = 5$ kg, $c = 6$ N·s/m and $k = 180$ N/m.

Solution

Every solution starts from free-body diagrams in a displaced position, then writes the equation of motion and reads off the vibration properties. Try the problem first, and then open one step at a time to check your work.

Step 1 · Draw the free-body diagram in a displaced position

The spring is stretched by δst + x and pulls up. The dashpot resists the downward velocity, so it also pulls up.

Measure $x$ downward from the static equilibrium position, where the spring is already stretched by $\delta_{st}$. At a general position the stretch is $\delta_{st} + x$.

Step 2 · Write the equation of motion

Newton’s second law in the downward direction gives

$$m\ddot x = mg - k(\delta_{st} + x) - c\dot x$$

At static equilibrium $k\delta_{st} = mg$, so the weight and the static spring force cancel. What remains is

$$m\ddot x + c\dot x + kx = 0, \qquad \delta_{st} = \frac{mg}{k} = \frac{(5)(9.81)}{180} = 0.2725\ \text{m}$$
Step 3 · Find the vibration properties $$\omega_n = \sqrt{\frac{k}{m}} = \sqrt{\frac{180}{5}} = 6.00\ \text{rad/s}, \qquad \zeta = \frac{c}{2\sqrt{km}} = \frac{6}{2\sqrt{900}} = 0.100$$ $$\omega_d = \omega_n\sqrt{1-\zeta^2} = 5.970\ \text{rad/s}$$

The system is underdamped, so it will overshoot.

Step 4 · Apply the initial conditions

The block starts from rest where the spring is unstretched, which is $\delta_{st}$ above equilibrium. So $x(0) = -\delta_{st}$ and $\dot x(0) = 0$. The underdamped response with these initial conditions is

$$x(t) = -\delta_{st}\,e^{-\zeta\omega_n t}\left(\cos\omega_d t + \frac{\zeta\omega_n}{\omega_d}\sin\omega_d t\right)$$

Differentiating gives $\dot x = \delta_{st}\,(\omega_n^2/\omega_d)\,e^{-\zeta\omega_n t}\sin\omega_d t$. The velocity is first zero again at $t_p = \pi/\omega_d$, which is the lowest point of the first swing.

Step 5 · Evaluate the overshoot

At $t_p = \pi/\omega_d = 0.526$ s we have $\cos\omega_d t_p = -1$ and $\sin\omega_d t_p = 0$, so

$$x(t_p) = \delta_{st}\,e^{-\zeta\pi/\sqrt{1-\zeta^2}} = (0.2725)\,e^{-0.3157} = (0.2725)(0.7292) = 0.199\ \text{m}$$

The total stretch of the spring at that moment is $0.2725 + 0.199 = 0.471$ m. Without damping the overshoot would equal $\delta_{st}$, so the block would drop to twice the static stretch.

Answer

The block overshoots static equilibrium by $0.199$ m (about 73% of $\delta_{st} = 0.2725$ m), at $t = 0.526$ s after release.

Explore

  • Use the “No damping” preset. Check that the block now drops exactly $2\delta_{st}$ below the release point.
  • Find the value of $c$ that removes the overshoot completely. How does it compare with $2\sqrt{km}$?
  • Double the mass. Both $\delta_{st}$ and $\zeta$ change. Does the overshoot ratio $x(t_p)/\delta_{st}$ go up or down?
